### Decisions taken, worth knowing before you review

- **X ships empty**, unlike the other three networks which default to demo URLs.
  A demo default would have added a dead link to every live footer on upgrade.
- **The stats strip is gone permanently, for every club** — you chose "rip the
  feature out". Numbers clubs previously entered are still in storage but will
  never render again.
- **The tab script was rewritten to bind every group, not the first.** The old
  version used a single `querySelector`; Home now has two tab groups, so the new
  switch would have been dead on arrival. This is why `activity_tabs` changed too.
- **The Global/Home tab split moves grouping only.** Every section keeps its
  `store_page`, so stored content addresses are unchanged and nothing needs
  migrating.
- **`.clubhouse-setup` changed from `height: 100vh` to `min-height`.** Without it
  the sticky save bar can only travel the first screenful.

### Next feature: third-party shortcodes

SureCart, SureDash, LatePoint, SureForms.

The blocker is not registration — WordPress runs shortcodes natively. It is that
ClubHouse escapes everything on output: every content field goes through
`Sections::e()`, so `[surecart_...]` typed into a field renders as literal text.

Supporting this means a **new field type** whose value is passed through
`do_shortcode()` instead of being escaped. That is a deliberate hole in the
escaping, so it has to be a separate, clearly-labelled field type — not a change
to the existing ones, which would silently unescape every field on the site.
Needs a design conversation before any code.
